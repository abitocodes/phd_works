# Part-time CS PhD → Postdoc Cases

조사일: 2026-07-04

파트타임(또는 직장 병행)으로 Computer Science 박사를 받은 뒤 **학계 포닥**을 구한 공개 사례를 모았다. 엄격 기준에 맞는 이름 있는 CS 사례는 공개 웹에서 거의 확인되지 않아, **유사·인접·제도 경로**를 신뢰도와 함께 정리한다.

## 요약

- **신뢰도 A(엄격: 파트타임 CS 박사 → 포닥 확인)** 사례는 이번 조사에서 **0건**.
- 공개된 파트타임 CS 박사 경험담은 대부분 **산업 잔류**(Microsoft, Google, FAANG SWE 등)로 끝난다.
- 포닥에 가까운 경로는 (1) **박사 기간 중 RA/연구직으로 CV를 쌓아** lectureship·포닥으로 직행, (2) **네트워크로 협상한 파트타임 포닥**, (3) **Industrial PhD → Industrial Postdoc** 같은 제도 경로에서 관찰된다.
- 실제로는 LinkedIn·개인 CV에만 있고 검색에 안 잡히는 사례가 있을 수 있다. 아래는 **공개 출처로 검증 가능한 범위**만 기록한다.

### 관찰된 패턴

1. **산업 병행 CS 박사 ≠ 학계 포닥 트랙**: 연구 주제를 회사 업무와 맞추면 졸업은 가능하나, 졸업 후 기본 경로는 산업이다.
2. **학계 진입은 “박사만”이 아니라 portfolio**: RA, 논문, 그랜트 경험이 병행될 때 lectureship·포닥으로 이어진다 (인접 분야 사례).
3. **파트타임 포닥은 공고보다 네트워크**: 그랜트 예산·단기 프로젝트 수요로 비공개 협상되는 경우가 많다.
4. **풀타임 전환 의지**: FAANG 병행 파트타임 포닥은 학계 구조와 잘 맞지 않는다는 회의적 의견도 있다.
5. **제도형 경로**: 덴마크 Industrial Researcher, NUS SoC-IPP 등은 “회사 고용 + 대학 연구”를 공식화한다. 학계 포닥보다 기업 R&D·Industrial Postdoc에 가깝다.

## 신뢰도 범례

| 등급 | 의미 |
|------|------|
| **A** | 파트타임(또는 직장 병행) **CS** 박사 + **포닥 취득**이 출처에서 확인됨 |
| **B** | CS 파트타임 박사이나 포닥이 아닌 경로, 또는 CS 포닥이나 **박사 모드 불명** |
| **C** | STEM/학계 파트타임 박사 → 포닥·lectureship 등 (**CS 아님**) |
| **D** | Industrial PhD / Industrial Postdoc 등 **제도적 유사 경로** (개인 성공담이 아님) |

### 1. Academia.SE 질문자 (Node.JS) — 신뢰도 B

| 항목 | 내용 |
|------|------|
| 배경 | FAANG 소프트웨어 엔지니어, 풀타임 근무 7년 |
| 박사 | Computer Science PhD를 **파트타임**으로 약 5년간 진행, 졸업 임박 |
| 이후 포지션 | **포닥 취득 사례 아님**. 파트타임 포닥 가능 여부를 질문한 단계 |

| 한계 | 성공 사례가 아니라 **추구 경로·동기**만 보여 줌 |

**시사점**: 산업 병행 파트타임 CS 박사 졸업자가 학계 포닥(특히 파트타임)을 고려하는 전형적인 프로필이다.

### 2. Academia.SE 답변자 (Cheery) — 신뢰도 B

| 항목 | 내용 |
|------|------|
| 배경 | PhD 후 포닥 2회 (CS 1회, Biology 1회) |
| 박사 모드 | **파트타임 여부 미확인** → A가 될 수 없음 |
| 이후 포지션 | **CS 파트타임 포닥** 경험. 당시 같은 도시 다른 기관에서 administrator 직을 병행 |
| 성사 요인 | 연구 그룹이 그랜트 프로젝트 도움이 필요했으나 **풀타임 포닥 예산이 없어** 파트타임 제안 |
| 한계 | “worthwhile part-time postdoc”는 *maybe*. 공고보다 **네트워크**로 찾는 경우가 많음 |

**시사점**: CS에서 파트타임 포닥 자체는 존재한다. 다만 “파트타임 박사 → 포닥”이 아니라 “포닥이 파트타임”인 사례다.

- 출처: 위 Academia.SE 질문의 Answer 1 (Cheery, 2023-05-17, 조회 2026-07-04)

**참고 (같은 스레드 Answer 2, Thomas Schwarz)**: FAANG급 도전적 직무와 유급 파트타임 포닥 병행은 학계 구조와 맞지 않으며, 연구 활동이 빠르게 끊길 수 있다고 본다. 연구를 유지하려면 **풀타임 학계** 또는 **연구 가능한 유급 직무**가 필요하다고 조언.

## 시사점 (포닥 지원 시)

1. **엄격 공개 사례가 없다**고 불가능하다는 뜻은 아니다. 다만 기본 경로가 아니므로 **의도적 설계**가 필요하다.
2. **논문·네트워크·연구 가시성**이 핵심이다. 산업 병행만으로는 학계 포닥 경쟁력이 약할 수 있다 (인접 분야에서는 RA portfolio가 결정적이었다).
3. **파트타임 포닥**을 원하면 공고보다 PI·연구 그룹에 **직접 제안·네트워크**하는 편이 현실적이다 (Academia.SE Cheery).
4. FAANG급 직무를 유지한 채 유급 파트타임 포닥을 병행하는 것은 **학계 구조와 충돌**할 수 있다 (Academia.SE Schwarz). 학계를 진지하게 고려하면 **풀타임 전환**을 전제로 하는 편이 안전하다.
5. **Industrial Postdoc** 등 제도 경로는 “박사 후 연구” 경험은 주지만, tenure-track용 학계 포닥과 **평가 기준이 다를 수** 있다.
6. Ted의 조언: 학계 커리어가 목표이거나 불확실하면 **풀타임 박사**가 덜 위험하다.

## 한계

- 공개 블로그·포럼·제도 페이지 기준이다. LinkedIn·비공개 CV의 사례는 포함하지 않았다.
- **이름 있는 “파트타임 CS 박사 → 학계 포닥”** 확정 사례(신뢰도 A)는 찾지 못했다.
- 익명 포럼 진술은 교차 검증이 어렵다.
- “포닥”의 범위(대학 postdoc, industrial postdoc, research associate, lectureship)를 넓게 보면 C·D 사례가 더 관련된다.
