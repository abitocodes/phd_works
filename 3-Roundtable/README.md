# 3-Roundtable

UNISA Postgraduate Research Roundtable 및 박사과정 **중간·진전 발표** 자료 보관 위치입니다.  
`1-Dissertation-Works/`, `2-Graduation/`과 동등한 최상위 경로에 둡니다.

제안서 전용 산출물이 아니라 **박사과정 전체 진행 보고**이므로 제안서 폴더 밖에 둡니다.

## 폴더 규칙

```
3-Roundtable/
  README.md
  YYYY-MM-DD/          # 발표·제출 일자 (일자 미상이면 YYYY-MM)
    index.html         # HTML 덱 (있으면)
    *.pptx             # PowerPoint (있으면)
    assets/            # 선택: 이미지 등
```

| 폴더 | 형식 | 내용 |
|------|------|------|
| `2026-05/` | `.pptx` | Returning / progress 발표 (May 2026) |
| `2026-07-30/` | `index.html` | Progress Roundtable 제출용 HTML 덱 |

한 회차에 pptx와 html이 둘 다 있으면 **같은 일자 폴더**에 함께 둡니다.

## HTML 덱 사용

1. 해당 일자의 `index.html`을 브라우저로 연다.
2. 키: `→` / `Space` 다음, `←` 이전, `F` 전체화면.
3. Forms 업로드용 PDF가 필요하면 브라우저 인쇄 → PDF로 저장.

## 새 회차 추가

1. `3-Roundtable/YYYY-MM-DD/` 폴더를 만든다.
2. 그 회차에 만든 `index.html` 및/또는 `.pptx`를 넣는다.
3. 이 README 표에 한 줄 추가한다.
