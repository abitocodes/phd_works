\subsection{Post-conditions}

Table~\ref{tab:pc-fields} maps the post-condition fields of a transaction, as the Stacks Blockchain API returns them \cite{hiroapi}, to the rules of Section~\ref{sec:mapping-rules}. Field names follow the API schema at the time of writing; the evaluation pins one API version in its configuration file and checks there how Originator mode and the \emph{may send} condition of SIP-040 are encoded.

\toprule
Field & Use \\
\midrule
\code{tx\_status} & Authorizations come from successful transactions only; fees count for every transaction the wallet originated, failed ones included. \\
\code{tx\_type}, \code{contract\_call.contract\_id} & Contract calls only; the contract named here is the entry contract $c(\tau)$. \\

\section{The synthetic example}
\label{app:toy}

The example of Section~\ref{sec:method-toy} is produced by \code{scripts/toy\_sybil\_example.py} with a fixed random seed. Its \ToyContracts\ honest contracts are a SIP-010 trait, six tokens that implement it, a math library, three pools that each use the trait and the library and pay out their two tokens inside \code{as-contract?}, a router that calls the three pools, a vault that pays out two tokens and uses the library, and a DAO that has enabled the vault and the router as extensions. Each of the \ToyWallets\ honest wallets authorizes one to three entry contracts (router, vault, DAO or a token) with values drawn from a log-normal distribution, and pays fees for $1+\mathrm{Poisson}(8)$ transactions, each costing a log-normal multiple of the minimum fee with median three. Each router user makes one to five router calls, each binding the two tokens of one pool. A deployment costs \ToyDeployFee\ minimum fees. Ranks count the contracts, the attacker's included, whose score is strictly higher than the target's, so ties go in the target's favor and the costs in Table~\ref{tab:toy-cost} can only be too low. PageRank uses the settings of Section~\ref{sec:method}; the fee cap $f_{\max}$ is left out. In the ablation with run-time bindings, the router's binding edges together get the same weight as its static references, split by how often each token was bound. Table~\ref{tab:toy-ranks} gives the target's rank for several attack sizes.
