# 유튜브 롱폼 내레이션 대본 지침 (한국어판)

이 대본은 박사 학위 논문 발표 슬라이드(59장, 클릭 단계 304개)를 유튜브용 가로 영상으로 만들 때 읽을 내레이션이에요. 목소리는 TTS(음성 합성, Supertonic 2)가 읽고, 자막은 따로 나가요. 화면은 슬라이드 그 자체이고, 우리가 그 위에 카메라 확대·강조 표시·용어 카드 같은 모션 그래픽을 얹어요.

## 1. 말투와 내용
- **해요체**, 친절한 선생님이 호기심 많은 고등학생에게 차근차근 설명하듯 써요. 발표 노트(`note`)도 해요체예요. 노트의 1인칭(저, 제 논문)은 그대로 써도 돼요. 화자는 이 논문을 쓴 사람이에요.
- 노트가 **내용의 기준**이에요. 노트의 주장, 숫자, 조건(예: "재분석", "사후", "탐색적", "등록", "미리 정함", "점검이지 검증이 아니에요")을 **빼거나 바꾸거나 부풀리지 마세요**. 노트에 없는 새 숫자·새 결과·새 주장을 만들지 마세요.
- 친절함은 이렇게 더해요: 처음 나오는 용어를 쉬운 말로 풀기, 왜 이걸 보는지 한 문장으로 이어 주기, 화면의 어디를 보면 되는지 안내하기("왼쪽 호박색 화살표를 보세요"), 노트에 이미 있는 비유를 조금 더 풀어 말하기, 장과 장 사이를 자연스럽게 잇기.
- 말로 들을 때 의미 없는 것은 빼거나 줄여요: 커밋 해시(43d8045 같은 것), 파일 경로, 블록 번호, 괄호 속 무대 지시("(지갑 창)" 같은 것; 이건 읽지 마세요). 단, 화면에 크게 나온 핵심 숫자는 말해요.
- 길이: 단계마다 노트 분량의 **대략 0.9~1.3배**. 노트가 아주 짧은 단계(한두 문장)는 화면을 안내하는 말을 조금 더해 2~4문장으로. 전체 영상은 약 80~95분이 될 거예요. 너무 늘어지지 않게, 같은 말을 되풀이하지 마세요.
- 연구 결과를 과장하지 마세요. "이겼다/졌다"는 노트가 말한 범위에서만. 원시 차수(허락한 주인 수를 그냥 센 값)가 이기는 곳은 그대로 말해요.

## 2. 한 줄(line)의 구조
각 단계는 `lines` 배열이에요. 한 줄 = 보통 한 문장(짧은 두 문장까지). 줄마다:
- `sub`: 자막에 보일 글. 숫자와 기호를 화면처럼 써요(예: "무제한 허락은 45.8%예요", "τ_b", "C-PR", "W1").
- `tts`: TTS가 읽을 글. **`sub`와 뜻이 정확히 같아야** 해요. 아래 3절의 규칙을 지켜요.
- `focus`: 이 줄을 말하는 동안 카메라·강조가 향할 앵커 id 배열(그 단계의 `anchors`에서만 고르기). 강조할 게 없으면 `[]`.
- `zoom`: `"none"`(확대 없이 강조만), `"soft"`(약 1.25배), `"close"`(약 1.6배). focus가 비면 `"none"`.
- `mark`: `"ring"`(둥근 테두리), `"underline"`(밑줄; 한 줄짜리 글에 좋아요), `"spot"`(나머지를 살짝 어둡게 하는 스포트라이트), `"none"`.
- `card`: (선택) 처음 나오는 핵심 용어를 정리해 주는 작은 카드 `{ "title": "허락 (allowance)", "body": "내 토큰을 계약이 대신 꺼내 쓸 수 있게 해 주는 기록" }`. title 20자 이내, body 45자 이내. **슬라이드당 최대 1개**, 꼭 필요할 때만(대본 전체에서 30개 안팎). 카드가 나오는 동안 슬라이드는 살짝 작아지고 아래에 카드가 떠요.

## 3. `tts` 글자 규칙 (가장 중요해요)
TTS는 숫자·영어·기호를 제대로 못 읽어요. 그래서 `tts`에는 **한글, 띄어쓰기, 마침표·쉼표·물음표·느낌표만** 써요. 숫자, 로마자, 그리스 문자, %, /, =, +, (, ), ·, ~, 따옴표는 모두 안 돼요.
- 숫자는 한글로 읽는 대로: 15,107 → "만 오천백칠", 6,221,665 → "육백이십이만 천육백육십오", 0.585 → "영 점 오팔오", 45.8% → "사십오 점 팔 퍼센트", 2026년 10월 → "이천이십육 년 시월", 6월 → "유월", 3분의 2 → "삼분의 이", 85번 → "팔십오 번", 1리터 → "일 리터", −0.028 → "마이너스 영 점 영이팔", [0.098, 0.122] → "영 점 영구팔에서 영 점 일이이 사이".
- 고유어 수 단위는 노트처럼: "세 개", "두 장", "네 컵", "한 번".

## 4. 모션 그래픽 단서 (`focus`, `zoom`, `mark`, `card`)
- 화면에서 지금 말하는 것을 가리키게 하세요. 그림(`imageWithAnchors`)에서 앵커 상자와 id를 확인하고 고르세요. 상자가 화면 전체에 가까운 앵커(큰 figure, 3d)는 확대(zoom)하지 말고 `ring`이나 `none`.
- 한 단계에서 카메라가 너무 자주 움직이지 않게: 인접한 줄은 같은 focus를 이어 쓰거나 `[]`. 대략 줄의 40~60%에 focus가 있으면 좋아요. 단계의 첫 줄은 보통 새로 나타난 것을 가리켜요.
- `close`는 작은 글자·식·숫자를 읽어 줄 때만. 3D 장면(kind "3d")은 확대하지 마세요.
- 앵커는 그 단계의 목록에 있는 id만 쓸 수 있어요(단계마다 id가 다시 매겨져요).

## 5. 장(섹션) 시작, 영상 시작과 끝
- `startsSection`이 true인 단위는 `chapter`를 넣어요: `{ "title": 섹션 제목, "subtitle": 한 줄 예고(30자 이내), "sub": ..., "tts": ... }` — 장 제목 카드 위에서 읽을 1~2문장(예: "세 번째 이야기, 데이터의 세계로 가 볼게요.").
- 첫 단위(`isFirstUnit`)는 `intro`를 넣어요: 영상 맨 앞 제목 카드 위에서 읽을 3~5줄. 인사, 이 영상이 무엇을 설명하는지, 끝까지 보면 무엇을 알게 되는지. 과장 없이.
- 마지막 단위(`isLastUnit`)는 `outro`를 넣어요: 2~4줄. 감사 인사와 짧은 정리. 구독·좋아요를 조르지 마세요.

## 6. 출력 형식 (JSON 파일)
```json
{
  "unit": "u05", "lang": "ko",
  "chapter": null,
  "intro": [],
  "steps": [
    { "slide": "s04-03", "step": 0,
      "lines": [
        { "sub": "...", "tts": "...", "focus": ["a4"], "zoom": "soft", "mark": "ring", "card": null }
      ] }
  ],
  "outro": []
}
```
- `steps`는 입력의 모든 단계를 순서대로 빠짐없이 담아요(slide, step 그대로).
- `chapter`, `intro`, `outro`는 해당하지 않으면 `null` 또는 `[]`.
- intro/outro/chapter의 줄은 `{ "sub", "tts" }`만 있으면 돼요.
